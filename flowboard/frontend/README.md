## 📌 Overview

FlowBoard is a modern Kanban-based task management application inspired by Trello and Linear. It combines a full-stack web application with a Machine Learning microservice to predict task delay risks and provide actionable insights.

---

## ✨ Features

- 🔐 JWT Authentication
- 📋 Kanban Board (To Do, In Progress, Done)
- 📝 Task CRUD Operations
- 👥 Teams & Projects
- 💬 Task Comments
- 📊 Analytics Dashboard
- 🤖 AI/ML Delay Prediction
- 🌙 Dark Mode
- 📱 Responsive UI

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/SudikshA-0/Flowboard-Updated-.git
cd Flowboard-Updated-
```

### Install Frontend

```bash
cd frontend/client
npm install
npm run dev
```

### Install Backend

```bash
cd frontend/server
npm install
npm run dev
```

### Start ML Service

```bash
cd flowboard_Backend

pip install flask flask-cors joblib scikit-learn

python app.py
```
